# Агрономическая модель «Агро-Радара»

Как считаются агрохимия, календарь фаз, индексы вегетации и статусы обработок.
Исходные числа — в `fields.json` (генерируются `data.py`), формулы — в
`agronomy.py`. Всё воспроизводимо: любой показатель можно пересчитать вручную.

---

## 1. Почва и питание

`fields.json → fields[].soil_analysis` — обследование слоя 0–30 см:

| Поле | Смысл | Единица |
|---|---|---|
| `sampled` | дата отбора | ISO |
| `ph` | pH солевой вытяжки | — |
| `humus_pct` | гумус | % |
| `n_mg_kg` | нитратный азот N-NO3 | мг/кг |
| `p_mg_kg` | подвижный фосфор P2O5 | мг/кг |
| `k_mg_kg` | обменный калий K2O | мг/кг |
| `s_mg_kg` | сера | мг/кг |
| `layer_cm` | мощность слоя | см |

**Обеспеченность:** `supply_pct = value / target × 100 %`, где `target` — из
`data.CROPS[crop].soil_target` (целевое содержание для культуры).

| supply_pct | Вердикт |
|---|---|
| < 70 % | низкое |
| 70–90 % | ниже нормы |
| 90–115 % | оптимальное |
| 115–140 % | выше нормы |
| > 140 % | высокое |

**Перевод в кг/га.** 1 мг/кг в слое 0–30 см при плотности ~1,0 г/см³ ≈ 3 кг/га:

```
need_kg_ha = max(0, target − value) × 3
доза = need_kg_ha / (доля д.в. × плотность)
```

| Элемент | Удобрение | Доля д.в. | Плотность | Единица |
|---|---|---|---|---|
| N | КАС-32 | 0,32 | 1,28 кг/л | л/га |
| P | аммофос N12P52 | 0,52 | 1,0 | кг/га |
| K | хлористый калий K60 | 0,60 | 1,0 | кг/га |

Пример: N 12,8 мг/кг при цели 18 → дефицит 5,2 × 3 = 15,6 кг д.в./га →
15,6 / (0,32 × 1,28) ≈ 38 л/га КАС-32.

**pH:** < 5,5 кислая (нужно известкование) · 5,5–6,0 слабокислая · 6,0–6,8
оптимальная · 6,8–7,4 нейтральная · > 7,4 щелочная.
**Гумус:** < 3 % низкое · 3–4 среднее · 4–6 повышенное · > 6 высокое.

«Узкое место» в интерфейсе показывается только если обеспеченность < 90 %.

## 2. Календарь фенологических фаз

Даты фаз генерируются при создании поля (`data.build_phases`):

* **яровые** — смещения в днях от посева (например, у кукурузы: всходы +10…20,
  3–5 листьев +21…35, … уборка +156…165);
* **озимая пшеница** — календарная схема с переходом через год: всходы 12.09–02.10,
  кущение 03.10–15.11, зимний покой 16.11–10.03, отрастание 11.03–12.04,
  выход в трубку, флаг-лист, колошение, цветение, молочная и восковая спелость,
  уборка 21.07–01.08.

Статус фазы считается от текущей (в демо — от `demo_date`): `пройдена`
(дата конца раньше сегодня), `текущая` (сегодня внутри), `предстоит`.
Дни до уборки — разница между `harvest_date` и сегодня.

Ограничения: фазы определяются календарём культуры, а не суммой эффективных
температур конкретного сезона; для реальных данных нужны сортовые GDD-шкалы.

## 3. Индексы вегетации (NDVI, EVI, SAVI, GNDVI)

Спутниковых снимков в контуре нет, поэтому используется **модель смешения
спектров**: из измеренного NDVI поля восстанавливается доля проективного
покрытия, по ней считаются остальные индексы. Ряд согласован и привязан к
реальному NDVI.

Смешение «почва ↔ растительность» по покрытию `f`:

```
R   = (1−f)·R_soil   + f·R_veg
NIR = (1−f)·NIR_soil + f·NIR_veg
G   = (1−f)·G_soil   + f·G_veg
B   = (1−f)·B_soil   + f·B_veg
```

| Канал | Почва | Растительность |
|---|---|---|
| R | 0,12 | 0,045 |
| NIR | 0,16 | 0,50 |
| G | 0,14 | 0,10 |
| B | 0,09 | 0,035 |

```
NDVI  = (NIR − R) / (NIR + R)
EVI   = 2,5 · (NIR − R) / (NIR + 6·R − 7,5·B + 1)
SAVI  = 1,5 · (NIR − R) / (NIR + R + 0,5)
GNDVI = (NIR − G) / (NIR + G)
```

Калибровка: покрытие на демо-дату оценивается по фазе (кривая
`CANOPY_ANCHORS`: 0,12 → 1,0 в цветении → 0,50 к уборке), численно ищется `f`,
при котором модельный NDVI равен измеренному, затем ряд масштабируется.
Поэтому `vegetation.current.ndvi` совпадает с `field.ndvi` (проверяется тестом).

Ограничения: абсолютные значения EVI/SAVI условны; тренд устойчивее. Замена на
реальные снимки — адаптер в том же формате `points[]`.

## 4. Обработки

`fields.json → spraying[]`: дата, вид (гербицид/фунгицид/инсектицид/
подкормка/протравивание/регулятор), препарат, дозировка, цель, ₽/га.
Даты — смещения от посева с детерминированным разбросом ±1 день.

Статус от демо-даты: `проведено` (дата раньше), `сегодня`, `план` + дней до
события. Считаются количество факт/план, ближайшая обработка и стоимость.

---

## 5. Севооборот

Текущий сезон + 6 будущих. Жёсткие правила:

* возврат культуры не раньше `rotation_return` (пшеница/ячмень/кукуруза/соя — 3,
  свёкла — 4, подсолнечник — 5 лет);
* запрещённые предшественники: подсолнечник после подсолнечника и свёклы,
  свёкла после свёклы и подсолнечника;
* бобовое звено (соя) — не реже раза в 4 года;
* чистый пар — не чаще одного раза за 7 лет и не подряд;
* зерновые получают бонус после хорошего предшественника.

У каждого года есть текстовое обоснование (`why`).

## 6. Технологическая карта

`GET /api/fields/{id}` → `tech_card` — единый план работ по полю, собранный из
календаря и журнала обработок:

| Операция | Дата | Стоимость |
|---|---|---|
| Предпосевная обработка почвы | посев − 21 день | 900 ₽/га |
| Основное внесение NPK | посев − 7 дней | 4 200 ₽/га |
| Посев (сорт) | `sowing_date` | 2 600 ₽/га |
| Гербициды / фунгициды / инсектициды | из `spraying[]` | из журнала |
| Уборка | `harvest_date` | 2 800 ₽/га |

Статус операции считается от демо-даты: `проведено`, `сегодня`, `план`
(с числом дней до события). Дополнительно считаются число выполненных и
плановых работ, стоимость факта и плана в ₽/га.

Это же используется на вкладке «Работы» в карточке поля: агроном видит, что уже
сделано, что предстоит в ближайшие дни и во что это обходится.

## 7. Что менять при подключении реальных данных

| Блок | Подменить | Код не меняется |
|---|---|---|
| Почва | `soil_analysis` из лаборатории | да |
| Нормы питания | `CROPS[].soil_target`, `removal_kg_t` | да |
| Календарь | даты фаз от агронома / сортовые шкалы | частично |
| Индексы | снимки NDVI/EVI/SAVI/GNDVI | да (адаптер) |
| Обработки | журнал из агросистемы | да |
| Техкарта | техкарты хозяйства (операции, нормы, стоимость) | да |
| Севооборот | план хозяйства | да |
