# Демо на 5 минут

**Цель:** за 5 минут показать все пункты критериев и не зависеть от интернета.

## Подготовка (за 10 минут до защиты)

- [ ] Сервер запущен: `Start.bat` или `%LOCALAPPDATA%\AgroRadar\AgroRadar.cmd`
- [ ] Открыт http://127.0.0.1:8000/ , масштаб браузера **100 %**, окно 1600×1000
- [ ] Вкладка «Поля», выбрано **Поле 1 · Бехтеевка** (критичное — эффектнее)
- [ ] Заранее открыт второй таб: http://127.0.0.1:8000/#state
- [ ] Телефон подключён к той же Wi-Fi, открыт `http://<IP>:8000/` (IP видно в консоли)
- [ ] Проверен чат: один вопрос задан заранее — видно, что отвечает
- [ ] На всякий случай: **видео-бэкап демо** (2–3 мин) на рабочем столе
- [ ] Презентация открыта рядом, слайды листаются стрелками

## Сценарий

| Время | Что делаем | Что говорим |
|---|---|---|
| 0:00–0:30 | Титул | «Агро-Радар» — рабочее место агронома: карта, погода, риски и ИИ-консультант. 12 полей, 1290 га, один экран вместо пяти таблиц. |
| 0:30–1:20 | Раздел «Поля» | Светофор: 2 критичных поля сверху. В карточке — культура, площадь, фаза, три риска. Это ответ на «где горит». |
| 1:20–2:10 | Поле → «Обзор», «Почва» | Показатели, рекомендации ML, карта поля. Почва: NPK факт/цель, дозы удобрений в кг д.в./га — то, что просил агроном. |
| 2:10–2:50 | «Фазы», «Работы», «Защита» | 11 фаз с датами, техкарта из 13 операций со стоимостью, план/факт обработок с препаратами и дозами. |
| 2:50–3:35 | «Севооборот» | Сетка 12 полей × 7 лет, пар, обоснование предшественника, «почему нельзя иначе». |
| 3:35–4:25 | ИИ-агроном | Вопрос: «Что делать в ближайшие дни?». Говорим: модель получает контекст поля, препараты берёт только из плана обработок, отвечает 20–40 с. Если долго — переключаемся на «Мониторинг». |
| 4:25–4:45 | Телефон | Открываем тот же адрес на телефоне: та же карточка поля, крупные кнопки, чат на весь экран. |
| 4:45–5:00 | «Скачать отчёт» | HTML-отчёт по полю: почва, фазы, обработки, севооборот, прогноз — можно распечатать или отправить. |

## Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| LLM отвечает дольше 40 с | «Пока модель думает — покажу Мониторинг»; вернуться к чату позже |
| LLM вернул 429 | Приложение само отдаёт детерминированный ответ из данных поля — сказать: «вот fallback, демо не падает» |
| Не открывается localhost | Проверить, что сервер запущен; запустить `%LOCALAPPDATA%\AgroRadar\AgroRadar.cmd` |
| Пропали вкладки/старый вид | `Ctrl+F5` (обновить service worker) |
| Нет интернета | Всё работает офлайн, кроме LLM; показать остальное |

## Вопросы, к которым быть готовым

- **«Данные настоящие?»** — Синтетика в формате выгрузки агросистемы; модель и агрономия считаются по реальным формулам, NDVI — модельный ряд по измеренному NDVI.
- **«Почему не React?»** — Один HTML + локальные библиотеки: офлайн, без сборки, мгновенный старт на слабом планшете.
- **«Где хранятся данные?»** — Локально в `fields.json`; БД и роли — следующий шаг.
- **«Сколько стоит?»** — LLM по токенам; при 429 — бесплатный fallback; установка и хостинг не требуются.
- **«Что дальше?»** — Реальные снимки NDVI, интеграция с агросистемой, задачи/роли, APK.
